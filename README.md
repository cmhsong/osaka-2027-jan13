## 고치는 법

```powershell
# 1. osaka-2027.html 을 편집
# 2. 웹 버전 다시 생성
powershell -ExecutionPolicy Bypass -File build.ps1
# 3. 배포
git add -A && git commit -m "일정 수정" && git push
```

`build.ps1`은 **UTF-8 BOM**으로 저장되어 있어야 합니다. BOM이 없으면 Windows PowerShell 5.1이 스크립트를 ANSI로 읽어 한글 메타태그가 깨집니다.
